# Cosmos

**Version:** 1.0
**Status:** Foundation
**Category:** Experience

---

# Purpose

This document describes the Cosmos itself.

It defines the user's first experience, the role of the Cosmos within the overall experience, and the principles that shape it.

Navigation, Nodes, Connections and Context Menus are described in their own dedicated documents.

---

# What is the Cosmos?

The Cosmos is the user's personal universe.

It is the highest level of the entire experience.

Everything exists inside it.

Projects, ideas, knowledge, relationships and future creations all become part of the user's own Cosmos.

Unlike traditional software, the user never switches between unrelated applications or pages.

The user always remains inside the same continuous environment.

---

# A Living Environment

The Cosmos is not a dashboard.

It is not a start page.

It is not a project overview.

Instead, it is an expandable environment that grows together with its user.

Every project becomes part of this universe.

Every new idea expands it.

Every user creates a different Cosmos over time.

---

# Navigation Through Place

The Cosmos is experienced as a place instead of a collection of interfaces.

Users navigate by moving through the environment rather than switching between pages.

Projects appear as individual galaxies within the Cosmos.

The Base always remains available as the user's home.

The user never leaves the Cosmos.

Only the current place within it changes.

---

# Project Galaxies

Projects are represented as individual galaxies.

Each project contains one central Main Node surrounded by related Nodes.

As projects grow, their galaxies naturally expand with them.

Every galaxy remains visually separated from the surrounding Cosmos while still belonging to the same universe.

---

# Calmness

The Cosmos should always feel calm and spacious.

Large empty areas are intentional.

Projects should never overlap.

Movement should never become distracting.

The surrounding universe exists only to reinforce the feeling of space without competing with the user's own projects.

---

# Visual Direction (Cosmos Theme)

Version 1 implements the Cosmos Theme.

Within this theme:

- the universe appears as a calm star field
- projects are surrounded by subtle cosmic nebulae
- Nodes appear as glowing stars
- Connections appear as soft energy beams
- distant background stars remain visually separated from interactive Nodes

Future themes may completely replace this visual presentation while preserving the same interaction model.

---

# Home

The user's Base is always accessible from within the Cosmos.

It acts as the permanent home of the user.

The Base remains available through its dedicated icon in the lower-right corner of the screen, regardless of the user's current location inside the Cosmos.

---

# Experience Goals

The Cosmos should always feel:

- calm
- spacious
- personal
- expandable
- alive
- intuitive

Users should immediately understand that they are entering their own environment rather than opening another application.

---

# Design Principles

The Cosmos follows these principles:

- One continuous universe.
- Projects are galaxies, not pages.
- Growth should feel natural.
- Navigation happens through places.
- Empty space is part of the design.
- Calmness is more important than visual intensity.
- Every future extension should integrate naturally into the same universe.

---

# Scope

This document describes only the overall Cosmos experience.

Detailed behavior for navigation, Nodes, Connections, Themes and Context Menus is described in their respective documents.

# Base

**Version:** 1.0
**Status:** Foundation
**Category:** Experience

---

# Purpose

This document describes the Base experience.

The Base is the user's personal environment inside the Cosmos.

It is the place where users research, plan and work.

Unlike the Cosmos, which represents the user's expanding universe, the Base represents a familiar place that remains personal and consistent.

---

# What is the Base?

The Base is not a dashboard.

It is not a project overview.

It is not a menu.

Instead, it is the user's home inside the Cosmos.

The Base contains the user's tools, workspaces, archive and companion.

It is the environment users naturally return to while working inside their Cosmos.

---

# Role

The Base serves as the bridge between exploration and productivity.

Users leave the Cosmos to enter their Base.

From there they can:

- access Workspaces
- continue projects
- explore their Archive
- use system tools
- interact with their Companion

The Base exists to support productive work without feeling like a traditional application.

---

# Living Environment

The Base should feel calm, personal and familiar.

It is designed to be a place where users spend long periods of time without feeling overwhelmed.

The environment should appear lived in rather than static.

Version 1 keeps this subtle.

Future versions may expand the feeling of a living home.

---

# Universal Structure

Every Base follows the same universal layout.

Themes may completely replace the visual appearance.

They may change:

- architecture
- materials
- decorations
- lighting
- atmosphere

They must not change:

- navigation
- room structure
- workspace locations
- interaction principles

This allows every Theme to remain immediately familiar while providing a completely different atmosphere.

---


# Object Integration

Every independently interactive element inside the Base is an Object.

Examples include:

- Base Window
- Doors
- Workspace Objects
- Companion
- Pet
- future decorations and Entities

The active Theme supplies their appearance. Their identity and behavior remain part of the universal Object Model.

---

# Relationship to the Cosmos

The Cosmos always remains active behind the Base.

Opening the Base does not leave the Cosmos.

Instead, the Base opens as the first Environment Window above the current Cosmos camera position.

Closing the Base immediately returns the user to the exact same location.

The user's journey through the Cosmos continues seamlessly.

---

# Experience Goals

The Base should always feel:

- personal
- calm
- familiar
- comfortable
- productive
- expandable

Users should feel like they are returning to their own environment rather than opening another interface.

---

# Design Principles

The Base follows these principles:

- Home before dashboard.
- Environment before interface.
- Familiarity before complexity.
- Productivity without pressure.
- Themes replace appearance, never structure.
- Every future extension should integrate naturally into the Base.

---

# Scope

This document describes the overall Base experience.

Individual Rooms, Workspaces, Companion and Pets are documented separately.

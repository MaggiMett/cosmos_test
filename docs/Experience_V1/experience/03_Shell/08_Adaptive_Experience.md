# Adaptive Experience

**Version:** 1.0
**Status:** Foundation
**Category:** Experience

---

# Purpose

This document defines how the Cosmos experience adapts to different device types.

Rather than creating separate applications for different devices, Cosmos provides one continuous experience that adapts naturally to the available space and interaction methods.

The goal is not to reproduce the desktop interface everywhere.

The goal is to provide the most appropriate experience for each device while preserving the same Cosmos.

---

# Design Philosophy

Responsive design focuses on adapting layouts.

Cosmos focuses on adapting experiences.

Different devices support different ways of interacting with the same Cosmos.

Every device connects to the same world.

Only the interaction changes.

---

# Desktop

Desktop is the primary Cosmos experience.

It supports the complete feature set including:

- Cosmos navigation
- Base
- Rooms
- Workspaces
- Window management
- productive multitasking
- creation workflows

Version 1 targets desktop environments exclusively.

---

# Tablet

Tablet extends the desktop experience into a portable environment.

The overall interaction model remains identical.

Future versions may optimize:

- touch interaction
- window arrangement
- workspace navigation

Tablet should remain suitable for productive work while adapting naturally to smaller displays.

---

# Mobile

Mobile is not intended to replicate the desktop experience.

Instead, it acts as a lightweight companion for the user's Cosmos.

Typical activities include:

- browsing the Cosmos
- reading Knowledge
- viewing the Archive
- reviewing Notifications
- communicating with the Companion
- creating quick Captures

Mobile prioritizes fast access over complex multitasking.

---

# Shared Cosmos

Regardless of device, every user interacts with the same Cosmos.

The current position, projects, knowledge and overall state remain shared.

Users never switch between different versions of their Cosmos.

They simply access it from different devices.

---

# Theme Support

Themes adapt naturally to different screen sizes.

They may adjust:

- layout
- spacing
- scaling
- interaction hints

They must never change:

- navigation philosophy
- interaction principles
- feature availability for the supported experience

---

# Future

Future versions may introduce:

- device-specific workspace layouts
- handheld Companion mode
- quick mobile workflows
- offline Capture
- synchronization across multiple active devices

These additions should extend the adaptive experience without changing the fundamental interaction model.

---

# Experience Goals

Adaptive Experience should always feel:

- consistent
- familiar
- natural
- connected
- purposeful

Users should immediately feel at home regardless of the device they are using.

---

# Design Principles

One Cosmos.

Many ways to access it.

Desktop remains the primary creation environment.

Mobile complements the desktop experience rather than replacing it.

The experience adapts.

The Cosmos remains the same.

---

This document defines how Cosmos adapts to different device types.

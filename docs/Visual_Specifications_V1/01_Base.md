# Base

**Version:** 1.0  
**Status:** Authoritative  
**Category:** Home

---

# Purpose

The Base is the user's permanent home inside Cosmos.

It provides a calm and familiar environment from which all workspaces, rooms and future ship areas are accessed.

The Base should always feel welcoming, personal and safe.

---

# Overview

The Base represents the interior of the user's personal ship.

It is displayed as a borderless environment rather than a traditional application window.

When opened, the Cosmos remains visible around the Base, reinforcing the feeling that the ship exists inside the universe.

---

# Object Template

## Layout

The Base occupies approximately eighty percent of the viewport.

The remaining area continues to display the surrounding Cosmos.

The Base contains:

- Main Room
- Cockpit
- Future Rooms

---

## Main Room

The Main Room serves as the central hub of the Base.

It remains visually open and uncluttered.

The center of the room should always remain free of furniture to preserve a clear view towards the Cockpit.

---

## Cockpit

The Cockpit is visible through an open passage at the back of the Main Room.

Inside the Cockpit two seats face a large panoramic window.

The Cosmos is visible through this window at all times.

The Cockpit should visually reinforce the feeling that the Base is part of a travelling ship.

---

## Companion

The Companion occupies the central area of the Main Room.

It serves as the primary visual presence inside the Base.

---

## Primary Workspaces

The Main Room permanently contains two primary Workspaces.

Knowledge Workspace

Positioned towards the rear left wall.

Creation Workspace

Positioned towards the rear right wall.

Both Workspaces appear as integrated furniture rather than floating user interface elements.

---

## Future Room Access

Space is intentionally reserved in front of both primary Workspaces.

These areas allow future doors leading to additional Rooms without changing the Main Room layout.

---

# Visual Identity

The Base is recognized by:

- warm interior
- open central space
- visible Cockpit
- permanent view into the Cosmos
- integrated Workspaces
- Companion presence

The Base should immediately feel like home.

---

# Cosmos Theme

## Architecture

The Base combines futuristic technology with a comfortable living environment.

It should resemble a personal exploration vessel rather than a military spacecraft.

---

## Lighting

Warm indirect lighting creates a relaxed atmosphere.

The Cockpit naturally draws attention through the light entering from the Cosmos.

---

## Materials

The active Theme defines:

- floor
- walls
- ceiling
- furniture
- decorative elements

---

## Workspaces

Primary Workspaces are visually integrated into the room.

They should feel like permanent furniture belonging to the ship.

---

# Visual States

The Base supports:

- default
- Workspace opened
- Room selected
- notification available

State changes should remain subtle.

---

# Animations

Version 1 animations remain restrained.

Examples include:

- smooth Base opening
- subtle ambient lighting
- Companion idle animations
- gentle Cosmos movement outside the Cockpit

Animations should reinforce comfort rather than spectacle.

---

# Future

Possible future additions include:

- additional Rooms
- customizable furniture
- alternative ship interiors
- decorative objects
- interactive Cockpit
- dynamic ambient lighting

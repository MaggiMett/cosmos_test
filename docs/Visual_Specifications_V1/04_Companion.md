# Companion

**Version:** 1.0  
**Status:** Authoritative  
**Category:** Cosmos

---

# Purpose

The Companion provides the user's permanent point of interaction inside Cosmos.

Unlike traditional application interfaces, the Companion is presented as a living character.

The Companion should always feel approachable, expressive and alive.

The Companion is an independent Cosmos Entity. It is not Journeyman, does not visually represent Journeyman and is not a substitute for the separate Journeyman Tool Window. It may surface ordinary notifications that open or focus that Tool.

---

# Overview

The Companion remains permanently visible while navigating the Cosmos.

It serves as both an interaction point and a visual presence inside the universe.

The Companion is not a Window.

It is a persistent Cosmos Object.

---

# Object Template

## Layout

The Companion occupies the lower-right corner of the Cosmos.

It remains visible regardless of the current Project.

---

## Interaction Area

The interaction hitbox is perfectly circular.

The visible Companion is not required to match this circular shape.

---

## Appearance

The default Cosmos Companion appears as an astronaut helmet containing the Companion's face.

Only the helmet and a small portion of the suit collar are visible.

The Companion should immediately read as a character rather than an application icon.

---

# Visual Identity

The Companion is recognized by:

- astronaut helmet
- expressive face behind the visor
- compact appearance
- permanent position
- living personality

The Companion should always appear friendly and approachable.

---

# Cosmos Theme

## Appearance

The helmet uses the Cosmos design language.

The visor remains transparent enough for facial expressions to be clearly visible.

The active Theme defines:

- materials
- reflections
- opacity
- lighting
- decorative details

---

## Expressions

The Companion communicates primarily through facial expressions.

Expressions should remain subtle and readable.

---

## Notifications

When attention is required, a small notification indicator may appear.

Version 1 uses a simple exclamation mark.

Notification indicators should remain unobtrusive.

---

# Visual States

The Companion supports:

- idle
- listening
- thinking
- speaking
- notification available

State changes are communicated primarily through facial expression.

---

# Animations

Version 1 animations remain restrained.

Examples include:

- blinking
- eye movement
- slight head movement
- subtle idle motion
- smooth expression changes

Animations should reinforce the illusion of a living character.

---

# Future

Possible future additions include:

- additional Companion skins
- animated visor reflections
- species variations
- cosmetic accessories
- seasonal appearances

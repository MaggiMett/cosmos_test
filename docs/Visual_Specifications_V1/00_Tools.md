# Tools

**Version:** 1.0  
**Status:** Authoritative  
**Category:** Tools

---

# Purpose

Tools provide the functionality of Cosmos.

Unlike traditional applications, functionality is not built into Workspaces.

Instead, Workspaces host Tool Windows chosen by the user.

---

# Overview

Every Tool is an independent Window.

Multiple Tools may be opened simultaneously inside the same Workspace.

Tools may be moved, resized and arranged freely according to the user's workflow.

---

# Philosophy

Workspaces define where work happens.

Tools define what work happens.

This separation keeps every Workspace flexible and reusable.

---

# Tool Windows

Every Tool follows the universal Window Template.

Tools may define their own internal layouts while remaining visually consistent with the Cosmos design language.

---

# Tool Independence

Tools should never depend on a specific Workspace.

The same Tool should behave identically regardless of the Workspace in which it is opened.

# Journeyman

**Version:** 1.0  
**Status:** Authoritative  
**Category:** Tool

---

# Purpose

Journeyman is the independent Cosmos Tool for planning, orchestration and development assistance.

It operates with awareness of the current Cosmos Context while remaining distinct from the Companion Entity.

Journeyman should feel like an experienced development collaborator rather than an external chatbot.

---

# Overview

Journeyman uses its own movable, resizable and closable Tool Window inside a Workspace.

It provides a familiar chat interface while remaining deeply integrated into the Cosmos environment.

The conversation should always feel contextual, focused and collaborative.

Journeyman is never represented by the Companion. The Companion retains its own visual identity and may only surface notifications that focus this separate Tool Window.

---

# Window Layout

Every Journeyman Window consists of:

- Context Bar
- Plan and Activity Area
- Conversation Area
- Input Area

---

## Context Bar

The Context Bar displays the information currently available to Journeyman.

Examples include:

- Active Project
- Active Workspace
- Selected Objects

The Context Bar should remain compact while giving users confidence that Journeyman understands the current situation.

---

## Conversation Area

The Conversation Area displays the chat history.

Messages follow a familiar conversational layout.

The conversation should prioritize readability and long-term discussions.

---

## Plan and Activity Area

The Plan and Activity Area displays:

- task state
- completed and active plan steps
- provider activity
- questions and errors
- validation results
- changed files and final outcomes

It should remain legible without turning the Tool into a terminal or notification center.

---

## Input Area

The Input Area provides:

- Text Input
- Send Action
- Attachment Support

Users may attach:

- Files
- Objects
- Discoveries

Attachments should appear directly inside the conversation.

---

# Visual Identity

Journeyman is recognized by:

- familiar conversation layout
- visible contextual awareness
- transparent planning and execution state
- collaborative atmosphere
- clean reading experience

Journeyman should feel approachable and intelligent.

---

# Cosmos Theme

## Appearance

Journeyman follows the active Cosmos Theme.

The conversation should remain visually calm to support extended discussions.

---

## Context Bar

The Context Bar should visually separate itself from the conversation while remaining unobtrusive.

Current context should always be understandable at a glance.

---

## Conversation

Messages should remain clean and readable.

Long conversations should never feel visually overwhelming.

---

# Visual States

Journeyman supports:

- idle
- planning
- executing
- validating
- awaiting review
- completed
- failed
- user typing
- responding
- thinking
- attachment available

State changes should remain subtle.

---

# Animations

Version 1 animations remain restrained.

Examples include:

- message appearance
- smooth scrolling
- thinking indicator
- attachment insertion

Animations should reinforce conversation without distracting from it.

---

# Future

Possible future additions include:

- voice conversations
- collaborative planning boards
- live repository exploration
- multi-agent conversations
- shared conversations with Entities

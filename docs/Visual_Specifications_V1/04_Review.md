# Review

**Version:** 1.0  
**Status:** Authoritative  
**Category:** Tool

---

# Purpose

Review presents Discoveries prepared by Cosmos.

Rather than requiring users to manually organize every piece of information, Cosmos continuously analyzes captured content and prepares meaningful Discoveries for review.

Review should feel calm, supportive and collaborative.

---

# Overview

Review is an independent Tool Window.

It presents a queue of Discoveries waiting for user confirmation, refinement or rejection.

Every Discovery represents a potential improvement to the user's knowledge.

---

# Window Layout

Every Review Window consists of:

- Toolbar
- Discovery Queue
- Discovery View

---

## Toolbar

The Toolbar provides quick access to:

- Search
- Filters
- Sorting

The Toolbar should remain compact and secondary.

---

## Discovery Queue

The Discovery Queue displays all pending Discoveries.

Every Discovery appears as a compact card.

Each card provides enough information for the user to understand why Cosmos created it.

---

## Discovery Card

A Discovery Card may contain:

- Title
- Type
- Short Summary
- Suggested Actions
- Priority
- Related Project

Cards should remain compact while inviting exploration.

---

## Discovery View

Selecting a Discovery opens its detailed view.

The user should immediately understand:

- what Cosmos discovered
- why it matters
- what actions are available

The Discovery View should prioritize readability over information density.

---

# Visual Identity

Review is recognized by:

- calm presentation
- Discovery Cards
- organized queue
- collaborative feeling

Review should never resemble a warning center or task manager.

---

# Cosmos Theme

## Appearance

Review follows the active Cosmos Theme.

The interface should encourage thoughtful review rather than urgency.

---

## Discovery Cards

Cards should appear organized and approachable.

Visual emphasis should remain subtle.

Priority may be communicated through small color accents.

---

## Empty Queue

When no Discoveries are available, the Review Window should communicate that Cosmos is quietly observing and organizing knowledge.

The empty state should feel satisfying rather than empty.

---

# Visual States

Review supports:

- pending Discoveries
- Discovery selected
- filtered
- search active
- empty queue

State changes should remain subtle.

---

# Animations

Version 1 animations remain restrained.

Examples include:

- Discovery appearance
- Discovery completion
- queue updates
- smooth transitions between Discoveries

Animations should reinforce calm productivity.

---

# Future

Possible future additions include:

- collaborative Discoveries
- AI confidence indicators
- grouped Discoveries
- scheduled Reviews
- Discovery history
- personalized Review workflows

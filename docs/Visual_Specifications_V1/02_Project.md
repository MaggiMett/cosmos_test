# Project

**Version:** 1.0  
**Status:** Authoritative  
**Category:** Cosmos Object

---

# Purpose

Projects are the largest visible Objects inside the Cosmos.

They organize related Nodes into one recognizable visual galaxy.

A Project should always be immediately distinguishable from every other Object.

---

# Overview

Every Project appears as a glowing galaxy floating inside the Cosmos.

The Project visually groups all contained Nodes while remaining easy to identify from a distance.

Projects should communicate identity, ownership and scale.

---

# Object Template

## Layout

A Project consists of:

- Project Nebula
- Main Project Node
- Preview Nodes
- Project Name

---

## Main Project Node

The Main Project Node is positioned at the visual center of the Project.

It acts as the anchor around which the Project is visually organized.

---

## Project Name

The Project Name is displayed directly below the Main Project Node.

It remains readable without dominating the Project.

---

## Nebula

The Nebula surrounds the complete Project.

Its shape is generated from the spatial distribution of the contained Nodes.

The Nebula should naturally expand where Nodes exist.

It should never appear as a perfect circle or fixed geometric shape.

Even Projects containing only a single Node receive a clearly visible Nebula extending beyond the Main Project Node.

---

## Preview Nodes

Outside the active Project view, up to nine Preview Nodes are displayed.

Preview Nodes should resemble a natural constellation.

Their arrangement should never appear perfectly symmetrical.

---

# Visual Identity

A Project is recognized by:

- its glowing Nebula
- one central Main Project Node
- a readable Project Name
- surrounding Preview Nodes
- being the largest visible Object inside the Cosmos

---

# Cosmos Theme

## Nebula

Soft glowing clouds.

Organic edges.

Smooth gradients.

The Nebula should feel alive without becoming visually noisy.

---

## Main Project Node

The brightest Object inside the Project.

Clearly distinguishable from Preview Nodes.

---

## Preview Nodes

Smaller than the Main Project Node.

Their brightness should remain secondary.

---

## Project Colors

Every Project has its own primary color.

The Cosmos Theme provides the default visual style.

Users may customize Project colors.

---

# Visual States

Projects support visible states such as:

- default
- highlighted
- active
- selected
- search result

State changes should remain subtle.

---

# Animations

Version 1 animations remain restrained.

Examples include:

- soft Nebula movement
- subtle Node glow
- smooth highlighting
- gentle appearance transitions

Animations should reinforce the feeling of a living galaxy.

---

# Future

Possible future additions include:

- animated Nebula evolution
- dynamic particle effects
- galaxy rotation
- seasonal Project skins
- procedural Nebula details

# Ship

**Version:** 1.0  
**Status:** Authoritative  
**Category:** Cosmos

---

# Purpose

The Ship provides permanent access to the user's Home.

It represents the user's personal vessel travelling through the Cosmos.

The Ship should always feel like a home rather than a navigation button.

---

# Overview

The Ship remains permanently visible while navigating the Cosmos.

It occupies the lower-right corner of the screen together with the Companion.

Selecting the Ship opens the Base.

The Ship is not a Window.

It is a persistent Cosmos Object.

---

# Object Template

## Layout

The Ship occupies approximately fifteen percent of the lower-right screen area.

Its size remains visually consistent across different display sizes.

---

## Interaction Area

The interaction area follows the visible silhouette of the Ship.

The interaction should feel generous without extending far beyond the visible model.

---

## Companion Relationship

The Companion is positioned slightly above and beside the Ship.

Both Objects remain visually connected while retaining independent interaction areas.

---

# Visual Identity

The Ship is recognized by:

- compact explorer vessel
- welcoming appearance
- permanent lower-right position
- visual relationship with the Companion

The Ship should communicate exploration, creativity and safety.

---

# Cosmos Theme

## Appearance

The Ship follows the Cosmos visual language.

It should resemble a small personal exploration vessel.

It should never appear military or aggressive.

---

## Materials

The active Theme defines:

- hull materials
- lighting
- engine glow
- windows
- decorative details

---

## Lighting

The Ship emits subtle ambient lighting.

Small illuminated windows reinforce the feeling that it is inhabited.

---

# Visual States

The Ship supports:

- default
- selected
- opening Base
- notification available

Visual changes remain subtle and readable.

---

# Animations

Version 1 animations remain restrained.

Examples include:

- gentle hovering
- subtle engine glow
- soft ambient lighting
- smooth Base transition

Animations should reinforce the feeling of a living vessel.

---

# Future

Possible future additions include:

- alternative Ship skins
- larger vessels
- customizable interiors
- animated docking
- boarding transitions
- seasonal decorations

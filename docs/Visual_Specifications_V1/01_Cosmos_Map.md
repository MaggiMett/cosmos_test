# Cosmos Map

**Version:** 1.0  
**Status:** Authoritative  
**Category:** Cosmos

---

# Purpose

The Cosmos Map is the primary visual environment of Cosmos.

It presents every Project and System Project inside one continuous universe.

The Cosmos Map provides orientation, exploration and visual identity.

---

# Overview

The Cosmos Map fills the entire application background.

It remains visible whenever no Room or Workspace overlays it.

Projects appear as individual galaxies floating inside deep space.

The Cosmos should immediately communicate scale, openness and possibility.

---

# Object Template

## Layout

The Cosmos Map occupies the entire viewport.

No traditional page layout exists.

The interface consists of:

- Cosmos background
- Project galaxies
- System Projects
- Connections
- Companion
- Ship
- Position Indicator

---

## Background

The background is almost black.

It should feel like deep space.

The background should never compete visually with Projects.

---

## Project Distribution

Projects are distributed across the Cosmos with generous spacing.

Large empty areas between Projects should reinforce the feeling of exploring a vast universe.

Projects should never feel crowded.

---

## Project Appearance

Every Project is represented as a galaxy.

Each galaxy contains:

- one central Project Node
- a surrounding nebula
- up to nine visible preview Nodes

Projects with only a single Node still receive a clearly visible nebula.

The nebula should always extend noticeably beyond the central Node.

---

## Position Indicator

The Position Indicator is permanently visible.

It is centered at the top of the screen.

Its appearance resembles a minimal RPG compass.

It displays the user's current location inside Cosmos.

---

## Companion

The Companion remains permanently visible.

Its default position is the lower-right corner.

It occupies approximately the lower-right fifteen percent of the screen.

The Companion should remain large enough for expressions, gestures and interaction to be immediately recognizable.

---

## Ship

The Ship remains permanently visible beside the Companion.

Together they create the permanent navigation hub of Cosmos.

Their position should remain visually consistent.

---

# Cosmos Theme

## Background

Almost black.

Subtle stars and distant galaxies create depth.

Background elements remain darker than every interactive Object.

---

## Project Galaxies

Projects appear as glowing nebulae.

Each Project forms its own visual galaxy.

The nebula softly surrounds its visible Nodes.

---

## Nodes

Nodes appear as stars.

They remain the brightest Objects inside the Project.

---

## Connections

Connections softly illuminate the space between related Nodes.

They should appear secondary to the Nodes themselves.

---

## Companion

The Companion visually feels alive.

Its appearance should naturally attract attention without becoming distracting.

---

## Ship

The Ship complements the Companion.

Both should visually belong to the same design language.

---

# Visual States

The Cosmos Map supports visible states such as:

- default
- Project highlighted
- Project active
- search result
- selected destination

State changes should remain subtle and readable.

---

# Animations

Version 1 uses restrained animations.

Examples include:

- subtle background movement
- soft nebula motion
- gentle node glow
- smooth camera movement
- companion idle animations

Animations should support immersion rather than attract attention.

---

# Future

Possible future additions include:

- animated galaxy formation
- Big Bang project creation
- dynamic cosmic events
- animated constellations
- additional ambient effects

Version 1 prioritizes clarity over spectacle.
